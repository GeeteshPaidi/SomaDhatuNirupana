# Data products (primary model, v3: instrumental amplitude fixed to 0 on the dayside)

Copied from `outputs/asr/` by the pipeline described in the top-level README. All ratios are weight ratios (oxide-closure model, Si reference).

| File | Content |
|---|---|
| `mapping_set_v3.parquet` | 578,530 quality-0 CLASS footprints. Columns: `source_file` (L1 FITS name), `month`, `clat`/`clon` (footprint centre, deg), `solarang` (deg), `goes_T_mk` (GOES isothermal temperature, MK), `goes_xrsb` (W m⁻²), `n_counts_fit` (counts in 1.15–7.5 keV), `r_Mg`, `r_Al` (Mg/Si, Al/Si), `sd_r_Mg`, `sd_r_Al` (1σ Fisher uncertainties). |
| `maps_2deg_v3.npz` | 2° equal-angle maps (90 × 180, row 0 = −90° lat, column 0 = −180° lon). `{Mg,Al}_mean` inverse-variance-weighted mean, `_se` standard error, `_wstd` weighted scatter, `_n` footprint count; `hit_all` / `hit_used` coverage by all dayside / quality-0 footprints. No smoothing or infill. |
| `summary_2deg_v3.json` | Pipeline stage counts and coverage statistics. |
| `sites_table_v3.csv`, `sites_stats_v3.csv` | Apollo/Luna landing-site comparison (1/2/5° radii). |
| `grs_table_v3.csv`, `grs_stats_v3.csv` | Lunar Prospector GRS comparison on 5° equal-area pixels. |
| `claims_v3.json` | Outcome of the pre-declared claim rule. |
| `score_diagnostics_v3.json` | Split-half reliabilities and correlation ceilings. |
| `headline_numbers.json` | Every number quoted in the manuscript (source of `paper_asr/numbers.tex`). |

The full per-spectrum fit tables for all 1,053,989 dayside spectra (~330 MB, including flagged fits) are not included; they are regenerated by `src/asr/run_all.py`.
